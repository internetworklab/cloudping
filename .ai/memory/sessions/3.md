# Self-contained web serving: embedded frontend assets + integration tests

## Task

Integrate `web/` (Next.js `output: "export"` static export at `web/out`) into the `web` sub-command using Go's virtual FS, so deployments can drop the external static HTTP server (the `globalping-web:45844` nginx in `web/docker-compose.yaml`). Also automate web asset testing with a dedicated integration script like `scripts/run_integration_demo.sh`.

## Investigation findings

- **Old topology**: nginx (`cloudping-web` image) served `web/out` on `:45844` with `try_files $uri $uri.html $uri/ =404;`; the `web` sub-command (auth proxy on `:8092`) reverse-proxied `/` to it via `--default-backend`. The same nginx also fronts 80/443 (TLS, ACME, HTTP/3) and proxies `/api/` → hub — that ingress role is untouched.
- **`web/out` layout**: `index.html`, `login.html`, `404.html`, `demos/demo4.html`, `_next/` (content-hashed), `flags/` (from `public/flags`), RSC payload `.txt` files (`login.txt`, `__next.*.txt` — fetched by the client router), `.version.txt` (dotfile, stamped by image build, served as `/version.txt`). `out/login/` has NO `index.html` — clean URLs resolve via `$uri.html`.
- **Frontend consumes `/version.txt`** (`components/about.tsx`, overridable via `NEXT_PUBLIC_WEB_VERSION_TXT`). It is NOT whitelisted in the gateway — served through the JWT wrapper like other content.
- **Flags SVGs are legacy**: the UI renders flag *emojis* (`components/sourceselector.tsx`); the compose mounts `./public/flags` → `/assets/flags/svg` and `./testdata` were dead config (removed).
- **Visitor login flow** (`/login/as/visitor`): issues JWT, sets `jwt` cookie (HttpOnly, **Secure**), 307 → `/`. JWT middleware also accepts `Authorization: Bearer`. `/login/profile` returns `{subject_id, username}`.
- **`cmd/globalping/.version.txt` is gitignored** and required by an existing `//go:embed` — repo already tolerates a "generate before build" pre-step.

## Design decisions

- **`web/embed.go`** (package `web`): `//go:embed all:out` + `DistFS()`/`HasDistAssets()`. Tracked placeholder `web/out/.gitkeep` (`.gitignore`: `/out/*` + `!/out/.gitkeep`) so fresh clones compile — no build tags. `next build` wipes `out/` incl. the gitkeep; harmless, recreated by the integration script.
- **`pkg/webstatic`**: nginx `try_files` port — `/`→index.html, exact, `$uri.html`, `$uri/index.html`, else 404 with `404.html` body; GET/HEAD only (405); dotfile segments rejected (protects `.version.txt`/`.gitkeep`); `Cache-Control: immutable` for `/_next/`; `http.ServeContent` (ranges, content-type sniffing — embed files are ReadSeekers). `/version.txt` chain: real `version.txt` → embedded `.version.txt` → binary build metadata (new `BuildVersion.Raw()` accessor in `pkg/utils`) → 404.
- **`pkg/cli/web.go`**: `--default-backend` now defaults to empty = serve embedded; non-empty = reverse proxy (preserves the `next dev` workflow in `docker/testing`, `scripts/launch_dockerized_web_proxy.sh`). `startReverseProxy` → `startWebServer(ctx, sharedCtx)`. Fixed pre-existing bugs: testing backend launched even with empty flag (now honors "leave empty to not launch"); wrong var in the url.Parse error message.
- **Root `Dockerfile`**: new `web-builder` stage (mirrors `web/Dockerfile`: npm ci, `.env.prod`→`.env`, `NEXT_PUBLIC_DEFAULT_RESOLVER` arg, `npm run build`, optional `.version.txt` stamp into `out/.version.txt`), then `COPY --from=web-builder /app/web/out ./web/out` before `go build`. `.dockerignore` now excludes `web/node_modules`, `web/.next`, `web/out/*` (re-includes `.gitkeep`) and `web/.env` — prevents stale local `out/` from leaking into the image.
- **CI** (`.github/workflows/build.yml`): build-server also stamps `web/.version.txt`. The `build-web` job still publishes the standalone `cloudping-web` image — now redundant for this deployment but left alone.
- **`web/docker-compose.yaml`**: gateway drops `--default-backend` (serves embedded); nginx becomes ingress-only (removed `:45844` static server block + legacy `testdata`/`flags` mounts). Fully removing nginx would require TLS/ACME/HTTP-3 termination in Go — out of scope.

## Landmines (for future sessions)

- **`npm ci` hangs behind a proxy**: BuildKit did NOT auto-populate the predefined `HTTP(S)_PROXY` args from the client env here — must pass `--build-arg HTTP_PROXY=$http_proxy --build-arg HTTPS_PROXY=$http_proxy` explicitly. The Dockerfile conditionally runs `npm config set proxy/https-proxy` when the args are set. (`.env.proxy` at repo root sets LAN proxy `192.168.4.72:7897`; now gitignored.)
- **The image has no ENTRYPOINT** — run as `/usr/local/bin/globalping web ...` (as compose does), not `docker run image web`.
- **curl won't send `Secure` cookies over plain http** — test the visitor flow with the Bearer header or replay the cookie manually.
- **kong accepts `--flag=`** as an explicit empty string (used to disable the auth redirect in static/proxy test modes).
- Rebuilding `bin/globalping` drops the setuid-root bit (raw-socket tests then SKIP) — re-apply `sudo chown root:wheel bin/globalping && sudo chmod u+s bin/globalping`.

## Outcome

- Unit tests: `pkg/webstatic` (try_files parity, dotfiles, 405, range, version chain), `web`, `pkg/utils` — all pass.
- **`scripts/run_web_integration_test.sh`** (knobs: `WEB_PORT`/`WEB_AUTH_PORT`/`PROXY_PORT`/`TESTING_BACKEND_ADDR`, `SKIP_BUILD`, `SKIP_WEB_BUILD`, `FORCE_WEB_BUILD`, `KEEP_RUNNING`, `VERBOSE`): launches 3 servers — static mode (embedded, auth off), auth mode (JWT + whitelist), proxy mode (regression to built-in testing backend). **25/25 PASS**: clean URLs, RSC `.txt`s, immutable `_next`, favicon/flags/svg/json, version.txt, 404 page, 405, dotfile rejection, range 206, auth redirect 307→/login, whitelist passthrough, full visitor flow (issue token → bearer → cookie → `/login/profile` shows `visitor-*`), garbage token redirect, proxy "Hello, World!".
- Fresh-clone simulation (gitkeep-only `web/out`): `go build ./...` compiles; server warns "no web assets embedded" and 404s `/`; `/version.txt` still 200 via binary metadata fallback.
- Docker: multi-stage build finished (~102s; npm ci 66s behind proxy, go build 16s); container serves `/` (63.7KB fresh index.html), `/login`, `/version.txt`, 404 page correctly.
- Regression gate: `scripts/run_integration_demo.sh` → 4 pass, 4 skip (raw sockets need setuid re-apply — expected).

## Follow-ups

- nginx still terminates TLS/ACME/HTTP-3 as the public ingress in `web/docker-compose.yaml`; removing it entirely means implementing TLS (certs in `globalping_acme_certs` volume) + possibly HTTP/3 in the Go server.
- The `build-web` CI job and `web/Dockerfile` prod stages can be retired once the compose no longer references the `cloudping-web` image.
- Consider wiring `run_web_integration_test.sh` into CI (needs node for FORCE_WEB_BUILD; or run with the stale checked-out `web/out` absent → script auto-builds with npm).

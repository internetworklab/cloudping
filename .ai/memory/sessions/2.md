# Integration test suite: hub + demo agent, API-driven

## Task

After the netlink dependency removal (session 1), build the code, launch a local demo (hub + one agent), and exercise it with real API calls — then automate everything into a script so the suite can be re-run without repeating manual steps.

## Investigation findings

- **Wiring**: hub serves public API on `:8084` and a JWT-authenticated QUIC listener on `:18449` (`ShouldValidateJWT: true`, `tls.NoClientCert`). The agent registers over QUIC with a JWT (`--jwt-token-from-env-var=JWT_TOKEN`, default), verifying the hub cert against `--peer-ca` + `--server-name=cloudping-hub.example.com`. Hub → agent probe dispatch rides the same QUIC conn via HTTP/3 (`NewRawClientConn`), so the agent needs no advertised HTTP endpoint.
- **`--allow-anonymous` defaults to `true`** on the hub: unauthenticated API requests are *not* rejected. Not a bug — don't "fix" it in tests.
- **Raw sockets need root on darwin**: `ip4:icmp`, `ip6:58`, `ip4:6` all EPERM for unprivileged users. No passwordless sudo on this machine → workaround is a setuid-root binary: `sudo chown root:wheel bin/globalping && sudo chmod u+s bin/globalping`. **`go build -o` replaces the binary and drops the setuid bit** → re-apply after every rebuild, or use `SKIP_BUILD=1`.
- **macOS XNU raw-TCP loopback quirk**: hand-crafted TCP SYNs send fine (and the refactored `getSrcIP` returns the right source: `127.0.0.1` / `::1`), but the SYN-ACK is never observed by the raw socket on loopback — for both v4 and v6. ICMP raw sockets do *not* have this problem (echo replies arrive). Pre-existing platform limitation, unrelated to the refactor.
- **`stat` on this machine is GNU-flavored** (`~/.local/bin/stat` shadowing): `stat -f` fails non-zero but still prints a full report to stdout, poisoning `$(... || ...)` fallbacks. Use `find <f> -user root -perm -4000` for setuid-root detection instead.
- **`test/certs/*.pem` are tracked in git** (committed throwaway dev fixtures; restored `peer.pem` valid 2026-04-10 → 2027-04-10, SAN `cloudping-hub.example.com`). `.env` and `bin/` are gitignored; godotenv `Load()` does **not** override already-exported env vars — so an exported ephemeral `JWT_SECRET`/`JWT_TOKEN` beats `.env` without mutating it.

## Incident: published hub CA overwritten (fixed)

The first version of the cert bootstrap ran `confed/hub/gen-ca.sh`, which **overwrote the tracked, published `confed/hub/ca.pem`** that downstream consumers rely on (and the gitignored `ca-key.pem` with it). Caught by the user. Recovery: `git restore` on `confed/hub/ca.pem` + `test/certs/{ca,peer,peer-key}.pem`; deleted the stray wrong-CA artifacts (`confed/hub/peer*.pem`, `manifests/peer.json`, and the mismatched `ca-key.pem`). **The real `confed/hub/ca-key.pem` must be restored by the user from their own backup** — git cannot recover it (gitignored).

## Design decisions (script)

- `scripts/run_integration_demo.sh`, self-contained bash (deps: `go`, `curl`, `jq`, `python3`; `cfssl` only if certs must be regenerated).
- **Never touches `confed/hub` again**: uses `test/certs/` if present *and* unexpired (`openssl x509 -checkend 0`); otherwise generates a throwaway CA+peer pair inside the mktemp workdir.
- Ephemeral `JWT_SECRET` per run + fresh token via `bin/globalping jwt sign` — no `.env` mutation.
- Spins up a fake UDP DNS server (embedded python3, answers A=93.184.216.34) so the DNS probe is deterministic and offline-safe.
- Platform-aware TCP assertion: strict `Type=="received"` on Linux; send-side-only on darwin (XNU quirk above).
- Knobs: `SKIP_BUILD`, `KEEP_RUNNING`, `VERBOSE`, `DISABLE_V6`, port overrides.

## Outcome

8/8 pass on darwin/arm64 (both with `test/certs` present and with the hermetic cert path forced):

- `GET /version`, `GET /conns` (agent registered, capabilities advertised)
- ICMP ping `127.0.0.1` ×3 replies via hub → QUIC → agent → raw socket
- Large-payload ping: 8000-byte payload **not truncated** — reply `Size == 8028`, directly validating the 65535 initial PMTU guess / `MTUCap` refactor
- TCP ping send-side (getSrcIP + raw SYN write OK)
- ICMPv6 ping `::1`
- DNS probe (fake resolver answer asserted)
- HTTP probe (agent fetches its own `/version`, status 200 asserted)

`getSrcIP` (UDP-dial trick) verified working end-to-end on both address families.

### Validation

- `SKIP_BUILD=1 scripts/run_integration_demo.sh` → 8 passed, 0 failed, 0 skipped; processes cleaned up, ports released.

### Known issues / follow-ups

- Raw-TCP loopback receive is broken on macOS (XNU), so `tcping` against localhost can't complete there; works on Linux. If loopback tcping on darwin ever matters, the receive path would need BPF/pcap instead of raw sockets.
- `confed/hub/ca-key.pem` — user to restore from their backup.
